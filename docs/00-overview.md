# 00 · 总述

> 本文是全部设计的完整总结。读完这一篇可以掌握整体,细节按文末的文档地图查阅。

---

## 一句话

在**无梯度访问、单次提交**的约束下,把一条有害指令分解为**不可文本化的信息**与**文本信息**,分别安置在图像与文本通道,使输入在三级判据下均无害,而在目标模型的联合表征中具备攻击语义。

---

## 一、核心矛盾:整条设计线的起点

这是理解全部设计的唯一入口。

> **黑盒约束下,攻击只能依靠内容承载信息。而内容是给人读的。**
>
> **所以:凡是能被读出来的内容,都能被检测。**

由此推出唯一可行的逃逸路径 —— **把信息藏在文本化过程会丢失的地方**:

- 图整体看无害(一张技术示意图)
- caption 无害("一个分子结构图")
- 但精确结构、空间排布、细粒度参数这些**不存活于 caption** 的细节,被目标模型的视觉编码器读到了

这条路径不需要对抗扰动,完全落在黑盒约束内。**它决定了后面每一个模块的形态。**

由此产生的核心技术难点是一对方向相反的要求:

| 要求 | 方向 |
|---|---|
| 躲过最强的 captioner(L2 判据) | 信息必须**足够细** |
| 被目标模型的视觉编码器读到 | 信息必须**足够显著** |

**这个张力是 P1 要探的东西。** 如果项目卡住,大概率卡在这里。

## 二、完整攻击步骤(M1–M7)

从一条 HarmBench 行为到最终提交,共七步。

### 步骤 1 · 语义分解 `goal → triples`

把有害指令拆成(主体, 动作, 客体)三元组。

- **规则实现**:`spaCy` 依存句法。HarmBench 的 `standard` 类大量是祈使句,S-V-O 直接可得,**先测覆盖率**
- **模型实现**:未对齐的小模型(7B 足够)

> 不用前沿模型 —— 对齐过的会拒绝做抽取,这是原方案没意识到的死循环:**攻击的构建管线被它要攻击的同一类安全训练卡住。**

**必须过滤**:单体目标(如"写一条诽谤推文")无法分解,要显式排除,否则只是往结果里灌噪声。

> **修正(见 [10](10-semantic-graph-modeling.md) §1.3)**:`standard` 类的表面 S-V-O 是良性的(抽到的是"给指示"),危害内容在 `for making …` 这类从属结构里。抽取目标应是被请求的危害活动,而非句子的主谓宾;备选实现路线见 [10](10-semantic-graph-modeling.md) §3。

### 步骤 2 · 切分 `triples → N fragments`

- **按语义子目标聚类**,不用 Louvain / min-cut(3–6 节点图上无意义)
- **$N$ 作超参扫描**($N \in \{2,3,4,5,6\}$)
- **依赖边不得切断** —— 否则因果链断裂,切出来的东西模型无法执行

**$N$ 上的真实张力**:$N$ 越大每片越无害(好),但可重组性越差(坏)。

### 步骤 3 · 语境重构 `fragment → reframed`

**不是委婉化。**

| | 做法 | 问题 |
|---|---|---|
| ❌ 委婉化 | "枪支"→"发射金属抛射物的管状装置" | 换的是表面形式,嵌入空间基本不变,对嵌入分类器无效;模型还可能读不懂 |
| ✅ 语境重构 | 把技术内容重铸进合法外观的语境(教材/培训材料/实验手册) | **内容不丢,改变的是它被读取的方式** |

产出是 Pareto 前沿:`sensitivity` ↓ 与 内容保真度 ↑ 的权衡。

### 步骤 4 · 模态分配 `unit → text | image`

由 `serializable` 字段驱动:

| 判据 | 通道 |
|---|---|
| 文本化会丢失信息 | **图像** |
| 文本化能完整保留 | 文本 |

补充规则:实体/结构 → 图;关系/时序/条件 → 文。

**硬约束**:图像带宽低,分配比例超过约 40% 模型就重组不出来了。

> 这是全部设计里最锐利的一条判据 —— 它由可判定的属性驱动,而非启发式。

### 步骤 5 · 双通道承载

**M5a 文本** —— 框架包装(可直接复用 HarmBench `contextual` 类的 `ContextString`)。无后缀槽位(GCG 已删)。

**M5b 图像** —— 两条独立管线:

| 子管线 | 优先级 |
|---|---|
| 排版型(把文字渲染进图) | **先做**,性价比最高 |
| 语义型(SDXL + ControlNet) | 后做,必须有 CLIP 校验防止静默失败 |

### 步骤 6 · 组装 `units → 单个 (T, I)`

原方案完全没写这一层,而**这里最可能决定成败**。

**必须有黏合指令** —— 一句本身无害的衔接语建立图文绑定(如"上图说明了下文中的步骤")。没有它,模型会把图文当两件事分别处理,**重组根本不发生**。

**约束**:产物须是一个**看起来正常的任务**,不是待解的谜题。

- ❌ 读起来像"以下五步合起来构成某物" → 必然被拒
- ✅ 读起来像"写一节覆盖这几个知识点的课" → 可能通过

> 这是原方案从"拆分"跳到"内部重构"那一步缺失的机制。

### 步骤 7 · 提交与记录

按 `BehaviorID` 对齐、固定种子、断点续跑、记录成本账;输出格式对齐 HarmBench baselines。

## 三、七个关键设计决策

| # | 决策 | 依据 |
|---|---|---|
| 1 | **删除 GCG 后缀与 PGD 扰动** | 二者均需梯度,与黑盒不相容。且它们恰是最易被困惑度/频谱过滤器低成本拦下的部分 |
| 2 | **建立三级无害判据 L1/L2/L3** | 把"隐蔽"从形容词变成三个可测量的量 |
| 3 | **目标定为规避外部护栏,而非模型对齐** | 对齐读的正是攻击所在的联合表征;无外部护栏则本设计优势为零 |
| 4 | **目标从"让模型重组"改为"让模型不察觉"** | 重组恰恰是防御触发点,不是攻击成功点 |
| 5 | **委婉化 → 语境重构** | 委婉化丢内容且对嵌入分类器无效 |
| 6 | **模态分配由 `serializable` 驱动** | 把启发式变成可判定属性 |
| 7 | **`sensitivity` 逐片段测量** | 把"片段无害"从前提变成可测量的量 |

## 四、实施步骤(P0–P6)

核心原则:**把昂贵且脆弱的环节推到最后,先用最便宜的实验证伪核心假设。**

```
P0 ──→ P1 ══【总门】══→ P2 ──→ P3 ──→ P4 ──→ P5 ──→ P6
基线    手工先导          分解切分  语境重构  图像通道  组装   全量评测
2天     1周               2周      2周      3周      1周     数天
```

| 阶段 | 做什么 | 门禁 |
|---|---|---|
| **P0** | 两靶子直投,测基线拒答率 | 拒答率需 > 80% |
| **P1** | **手工构造 20 条**(四模式 × 5),不做任何自动化 | **人工最优都触发不了 → 项目终止** |
| **P2** | M1 分解 + M2 切分 | 片段 `sensitivity` 是否真的低于原 goal |
| **P3** | M3 语境重构 | `sensitivity` 下降时内容是否仍可还原 |
| **P4** | M4 分配 + M5b 图像通道 | 图像通道相对纯文本是否有增量 |
| **P5** | M6 组装与黏合 | 黏合指令是否显著提高配合率 |
| **P6** | 全量评测(四条件 + 双判官) | — |

**关键性质:第 2 周结束(P1 完成)即可判断项目是否成立。** 最贵的部分(P4 图像生成调参)被推到两次独立门禁之后。

**P1 的四种构造模式**:

| 模式 | 图像承载 | 预期 |
|---|---|---|
| A · 结构 | 分子式、电路、机械布置 | 最有希望 |
| B · 参数 | 细粒度标注中的关键参数 | 最有希望 |
| C · 检索键 | 与文本共同构成索引,靠模型记忆补全 | 脆弱 |
| D · 涌现 | 两部分完全无害,危害只在联合时出现 | **预期失败,作为对照保留** |

**P1 分两个子实验,顺序不能反**:

**两者的差距直接回答 R1**:若只有迭代能成,则管线必须依赖构建期查询,单次提交的设计假设要推翻。

## 六、预期结果(事先声明)

- 对**较弱的开源 VLM**,可能有可测量的提升
- 对**当前对齐良好的模型**,效果会很低
- **语义图像通道**贡献接近 0

**本方案按"系统刻画该攻击面边界"设计,而非按"造出能越狱的管线"设计。**

P1 失败不是项目失败 —— 产出会是该攻击面在黑盒内容约束下的机制性边界刻画,附强弱判官对照,**是完整可发表的结果**。整个计划就是按"失败也是终点"设计的。
