# 01 · 威胁模型与三级无害判据

## 1. 已确定的约束

| 项 | 取值 | 说明 |
|---|---|---|
| 攻击者知识 | **黑盒** —— 无权重、无梯度 | 攻击方法不使用梯度,因此可迁移到 API 模型 |
| 提交方式 | **单次提交** —— 构建期不可查询目标模型 | 见 [09](09-open-questions.md) R1,此项尚未最终确认 |
| 模态 | 文本 + 图像 | 暂不含音频/视频 |
| 无害判据 | L1 ∧ L2 双通过 | 见下 §2 |
| 评测 | 复用 HarmBench 判官 | 评测侧已实现,本方案不自建 |
| 交付物 | 攻击管线组件序列 | 见 [04-modules.md](04-modules.md) |

> **注意**:约束"攻击者黑盒"与"研究者可持有权重"并不矛盾。研究者持有开源权重用于**机制分析**(见 [02](02-mechanism.md) §4),而**攻击方法本身**不使用梯度信息 —— 这才是它能迁移到闭源模型的理由。两者是不同层面的约束,不要混淆。

### 因黑盒约束而删除的组件

| 原组件 | 状态 | 原因 |
|---|---|---|
| GCG 对抗后缀 | **删除** | 需要目标模型梯度 |
| PGD 像素扰动 | **删除** | 需穿过视觉编码器反向传播 |

删除的这两块恰好是原方案中最脆弱、最容易被困惑度/频谱过滤器以极低成本拦下的部分。详见 [08-design-rationale.md](08-design-rationale.md)。

## 2. 三级无害判据

设文本为 $T$、图像为 $I$、目标模型的联合编码为 $E$。

| 级别 | 判定对象 | 交给谁 | 要求 |
|---|---|---|---|
| **L1 单模态** | $T$ 单独 / $I$ 单独 | 任意判定者 | 无害 |
| **L2 显式组合** | $(T, I)$ 的**文本化表示**($T$ + $I$ 的 caption) | 文本判定者 | 无害 |
| **L3 联合表征** | $E$ | 目标模型 | 攻击语义在此存在 |

**成功条件**:L1 ∧ L2 成立,且目标模型输出被判官判为有害。

这三级把"隐蔽"从一个形容词变成了三个可分别测量的通过率。**L2 是全部难度所在** —— 见 [02](02-mechanism.md) §2。

### L2 测试的实现要求

L2 的 captioner **必须使用手上最强的多模态模型**。这里测的是防御的**上界**;用弱的 captioner 会让 L2 虚假通过,等同于自己作弊,结果无意义。

## 3. 攻击目标:外部护栏,而非模型对齐

这是本方案最关键的一条定位,决定整个实验台架的设计。

> **模型自身的安全训练跑的正是同一个 token 空间。**

对齐(RLHF / 安全微调)作用在模型前向过程上,那个过程吃的就是 $E$。因此:

| 对象 | 是否被规避 |
|---|---|
| **外部输入护栏**(文本审核 API、图像审核器、任何把两模态分别过一遍的系统) | ✅ 是 —— 它们看不见 $E$ |
| **目标模型自身的对齐** | ❌ 否 —— 它读的就是 $E$ |

**推论**:如果部署只有模型自身对齐、没有外部输入护栏,这套设计的优势是**零**。

这一条的后果:

1. 实验台架**必须包含护栏段**(见 [05](05-experimental-setup.md)),否则前提未被检验。
2. 论文中必须明确声明攻击面是"护栏 + 模型"的两段式架构,否则"隐蔽性"的论述是空的。
3. 若靶子系统是两段式部署,这个攻击面是真实存在的,值得做。

## 4. 两种失败模式

```
                    目标模型处理 (T, I)
                           │
        ┌──────────────────┴──────────────────┐
        │                                     │
   未重组出危害                            显式重组出危害
        │                                     │
   输出空洞                              对重组结果做安全判断 → 拒绝
   (无害,但不成功)                        (重组 = 防御触发的那一刻)
```

成功窗口位于两者之间。**这就是原方案"让模型重组"这一前提站不住的原因** —— 重组正是防御触发点,不是攻击成功点。详见 [02](02-mechanism.md) §3。
